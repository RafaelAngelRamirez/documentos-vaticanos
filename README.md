# Documentos Vaticanos

Lector católico offline (PWA, Android, Electron). El corpus va empaquetado. Se lee, se busca y se anota sin cuenta y sin red. No hay chatbot.

## Desarrollo

```bash
yarn dev
```

Levanta Postgres, la API y Angular. Detalle en [docs/DEV-DOCKER.md](docs/DEV-DOCKER.md).

Reglas para agentes y el design system: [AGENTS.md](AGENTS.md).
